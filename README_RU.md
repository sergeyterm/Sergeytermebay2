# Sony Vegas Video 2.4

Личный Android-видеоредактор с классической компоновкой Sony Vegas. Минимальная
версия Android — 10 / API 29; compile/target SDK 35. Имя пакета остаётся
`com.personal.sonyvegasvideo`, versionCode 7. Это самостоятельное неофициальное
приложение, не продукт Sony/VEGAS и не полная настольная версия.

## Рабочий процесс

Откройте ролик через File → Open video или кнопку импорта. Основной экран позволяет
задавать начало и конец, просматривать выделение, добавлять маркеры и эффекты,
сохранять проект и экспортировать MP4. File → Timeline editor открывает монтажную
последовательность: импорт нескольких файлов, разрезание, удаление с закрытием
промежутка, перестановка, Undo/Redo и общий экспорт.

Исходные медиа не изменяются. Проект `.vvp` хранит ссылки на них, границы и настройки.
Файл проекта нужно открывать на устройстве, где исходники всё ещё доступны.
Новые проекты обоих экранов используют общий формат; старые варианты
`VegasVideoProject` и `VegasVideoSequence` читаются для совместимости. Проекты
настольного VEGAS `.veg` и пакеты ресурсов KineMaster не являются форматом этого приложения.

## Эффекты и панели

Video FX открывает параметры обработки: яркость, контраст, насыщенность, оттенок,
цветовые пресеты, размытие, мозаика и хромакей. Настройки применяются к реальным
кадрам через Media3; предпросмотр и обработанный экспорт используют один набор эффектов.

Transitions предлагает Dissolve, Cross, Wipe и Cascade. В Timeline editor с двумя
и более клипами они перекрывают соседние события: одновременно видны оба ролика,
звук плавно перетекает между ними, а общая длительность сокращается на перекрытия.
Переходы видны в предпросмотре и сохраняются в MP4. На основном экране с одним
роликом эти настройки задают появление/исчезновение выбранного диапазона.

Media Generators создаёт одноцветный фон, текст, шахматный фон или градиент.
Текст также можно наложить на исходное видео. Добавленное видео может служить
накладываемым слоем, а выбранный аудиофайл — музыкальной дорожкой. Панель настроек
слоёв задаёт относительную громкость/геометрию и позволяет убрать слой.

Хромакей удаляет выбранный цвет. Если настроен накладываемый видеослой, ключ
применяется к нему; без слоя он действует на основное видео. Результат зависит
от освещения, цвета исходника и порога. Автоматическое отслеживание объектов,
генеративные AI-эффекты и библиотека облачных пакетов в эту версию не включены.

## Управление

- Границы задаются золотыми ручками таймлайна или точным вводом времени.
- Таймлайн поддерживает перемотку, масштаб и прокрутку; Fit показывает весь проект.
- Транспорт: воспроизведение/пауза, стоп, начало/конец, шаг по кадрам; Loop повторяет диапазон.
- Undo/Redo восстанавливают изменения монтажа и настроек; одна операция перетаскивания создаёт одну запись.
- Маркеры позволяют помечать время, переходить к отметкам и удалять их.
- Master задаёт итоговую громкость; Mute отключает исходный звук. Добавленная музыкальная дорожка управляется отдельно.
- Регуляторы дорожек меняют непрозрачность видео, громкость и панораму звука; кнопки FX открывают настройки эффектов.
- Rate меняет скорость предпросмотра; экспорт сохраняет скорость монтажа.
- Save project сохраняет состояние; Save project as создаёт отдельный `.vvp`.
- Render As сохраняет MP4 в `Movies/Sony Vegas Video`; результат можно открыть или отправить через Android.

Необходимые для медиа операции доступны после импорта. При недоступном источнике,
неподдерживаемом декодере или повреждённом проекте приложение сообщает причину;
повторный импорт позволяет восстановить доступ. Отмена выбора файла не должна
сбрасывать текущий проект.

## Экспорт

Обработанный экспорт Media3 декодирует и кодирует H.264/AAC MP4. Это позволяет
объединять источники с разными параметрами и применять эффекты. Выход ограничен
720p с сохранением соотношения сторон и SDR. На слабом устройстве экспорт может
быть медленнее воспроизведения. Возможность декодировать конкретный источник
зависит от системных кодеков; DRM не поддерживается.

Отмена и обработанная ошибка удаляют временные/неопубликованные результаты.
Экспорт не равнозначен системной фоновой задаче: принудительное завершение
процесса может прервать его. Во время длительного сохранения оставляйте приложение открытым.

Старый путь remux без перекодирования остаётся в коде для регрессионных проверок.
Он требует совместимых кодеков и округляет границы к ключевым кадрам; это отличается
от обработанного режима интерфейса.

## Установка и сборка

APK локальной сборки: `build/sdk/Sony_Vegas_Video_v2.4.apk`. Для обновления поверх
предыдущих личных версий нужен тот же сертификат. Публичный CI применяет временный
ключ, поэтому его APK не заменяет личную подписанную сборку автоматически.

Сборка: JDK 17, Gradle 8.9, SDK 35, Build Tools 35.0.0, Bash, Python 3.
Для генерации синтетических роликов тестов требуется FFmpeg >= 6.
Команды и CI-артефакты описаны в [README.md](README.md).

## Проверки

`bash tools/run-logic-tests.sh` выполняет чистые Java-тесты математики времени,
истории, последовательности и MP4-заголовков; также подключает тесты модели эффектов.
`bash tools/run-device-tests.sh` устанавливает два debug-APK и выполняет регрессионный,
эффектный и два UI-набора на подключённом устройстве. Тесты используют только
синтетическое видео. UI-выбор документов частично моделируется возвратом Android
picker, чтобы проверить обработку импорта/сохранения без зависимости от провайдера файлов.

Матрица GitHub Actions запускает их на API 30 и API 35. Журналы и снимки сохраняются
даже после ошибки. Фактический успех и список прошедших сценариев определяются
результатами конкретного запуска Actions, а не этим описанием. Физический Fold7
требует отдельной пользовательской проверки.
