# Sony Vegas Video 2.3 — Classic Workspace

Личный неофициальный Android-видеоредактор с компоновкой классического Sony Vegas Pro 13. Приложение не является продуктом Sony/VEGAS или портом VEGAS Pro. Версию 2.1 пользователь успешно установил и запустил на Samsung Galaxy Z Fold7; эта версия меняет интерфейс и добавляет управление проектом.

## Новое в версии 2.3 — настоящий монтаж

В File → Timeline editor или через кнопку ножниц открывается отдельное монтажное окно.

- Добавление нескольких роликов через системный выбор файлов, максимум 64 фрагмента.
- Разрезание выбранного фрагмента в позиции курсора по ближайшему внутреннему ключевому кадру (кнопка ножниц / S).
- Удаление фрагмента с закрытием промежутка. Исходные файлы не меняются.
- Перестановка выбранного фрагмента кнопками влево/вправо.
- Undo/Redo для монтажа и автоматическое сохранение последовательности между запусками.
- Предпросмотр последовательности, Mute и склейка в единый MP4 через Render As….
- Сохранение и открытие отдельного монтажного проекта .vvp формата VegasVideoSequence.

При первом открытии монтажного окна текущий фрагмент из основного экрана добавляется в пустой монтаж. Если монтаж уже сохранён, открывается он. File → New создаёт пустую последовательность; Add videos добавляет источники. Обычный .vvp основного триммера и монтажный .vvp имеют разные форматы и открываются в соответствующих окнах.

Экспорт выполняется без перекодирования. Должны совпадать видеокодек, разрешение, поворот, параметры кодека/CSD и цветовые метаданные; с включённым звуком — также аудиокодек, частота дискретизации, каналы и конфигурация аудиокодека. Иначе экспорт отклоняется с пояснением. Для разных аудиоформатов можно включить Mute. Произвольные файлы с разными форматами требуют будущего перекодирования и пока не склеиваются.

Границы экспорта привязаны к ключевым кадрам. Предпросмотр при переключении источника может кратко буферизоваться. В основной оболочке сохранён прежний триммер одного ролика. Обновлён значок по образцу классической киноплёнки Vegas; название осталось Sony Vegas Video.

Сборка на GitHub подготовлена в двух заданиях (build и android-tests); инструкция — README.md. Фактический статус запуска проверяйте на вкладке Actions репозитория.

## Интерфейс

Вместо прежнего вертикального экрана теперь рабочее пространство редактора: меню File / Edit / View / Insert / Tools / Options / Help, панель инструментов, док-панели Project Media / Explorer / Transitions / Video FX / Media Generators, Video Preview, Master Preview, таймлайн с линейкой, видео- и аудиособытиями, курсором и выделением, нижняя панель транспорта и строка состояния. Ширина боковых панелей адаптируется к экрану; на узком экране Master скрывается, его громкость доступна через Options. View позволяет скрыть медиапанель и увеличить предпросмотр.

Миниатюры берутся из открытого видео. Звуковая волна и пиковый индикатор вычисляются из декодированного PCM, без искусственно нарисованных данных. Для длинных/сложных файлов анализ ограничен по времени: если он не завершился, отображается нейтральная аудиодорожка. Индикатор показывает пики файла с учётом громкости предпросмотра, а не точный мгновенный уровень аудиовыхода.

Transitions, Video FX и Media Generators показывают организацию интерфейса и не применяют обработку. Split, удаление и перестановка доступны в отдельном Timeline editor. Дополнительные одновременно смешиваемые дорожки пока не поддерживаются; функциональность всего настольного VEGAS не перенесена.

## Управление

- File → Open video — импорт ролика. Можно открыть видео и из галереи через системное «Открыть с помощью».
- Золотые ручки на линейке задают начало и конец выделения.
- Касание дорожки/линейки перематывает видео. Долгое нажатие открывает точный ввод времени. Время отображается как ЧЧ:ММ:СС.мс.
- Два пальца изменяют масштаб; нижний скроллбар прокручивает таймлайн. Есть кнопки zoom in / out / fit.
- Undo / Redo отменяют и повторяют выбор границ и отключение звука; одно перетаскивание — одна запись истории.
- M на аудиодорожке отключает звук при предпросмотре и экспорте.
- Маркеры добавляются через Insert → Marker или кнопку флажка. Insert → Markers позволяет перейти к маркеру или очистить их.
- Транспорт: начало, предыдущий/следующий кадр, воспроизведение, пауза, стоп, конец; Loop включает повтор выделенного фрагмента. Перемотка использует MediaPlayer.SEEK_CLOSEST; точность зависит от декодера.
- Master изменяет громкость только предпросмотра. Rate также действует только на предпросмотр; экспорт сохраняет исходную скорость и громкость, кроме режима Mute.
- File → Save project сохраняет рабочее состояние внутри приложения. Save project as… создаёт отдельный JSON-проект `.vvp` с источником, границами, режимом звука и маркерами. Видеофайл в проект не встраивается; нужен доступ к исходному URI на том же устройстве. Формат `.veg` не поддерживается.
- File → Render As… сохраняет выбранный фрагмент MP4 в `Movies/Sony Vegas Video`. Во время экспорта доступна отмена.
- File → Open rendered video / Share rendered video открывает или отправляет готовый результат.

С аппаратной клавиатурой: Space — play/pause, Ctrl+O — открыть видео, Ctrl+S — сохранить рабочее состояние, Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y — Undo/Redo, стрелки — шаг по кадрам, Home/End — начало/конец выделения, M — маркер.

## Установка и обновление

Готовый APK: `apk/Sony_Vegas_Video_v2.3.apk`. Минимум Android 10 / API 29, compile/target SDK 35. Нативных библиотек `.so` нет; приложение не требует разрешения на интернет. versionCode 6. Подпись локальной сборки зависит от ключа; CI использует временный debug-ключ.

Скачайте APK на телефон и откройте через «Мои файлы» → «Загрузки». Android предложит обновить установленную 2.1. Если приложение с этим package ID подписано другим ключом, обновление поверх него невозможно. Сборки 2.1 и 2.2 из этого проекта используют один ключ.

## Экспорт и ограничения

В основном триммере — один источник. В Timeline editor — последовательность совместимых источников. Из каждого берутся первая видеодорожка и первая аудиодорожка. MP4 сохраняется без перекодирования: начало округляется к предыдущему ключевому кадру, конец — к следующему или концу исходника, чтобы сохранять полные группы кадров с B-кадрами. Фактические границы сообщаются после сохранения. Сохраняется поворот видео. Исходный кодек должен поддерживаться MediaMuxer; DRM и неполные кадры не поддерживаются. Размер одного сжатого кадра ограничен 64 МБ. Дополнительные аудиодорожки, субтитры, главы и GPS-метаданные не переносятся.

Экспорт переживает пересоздание Activity в живом процессе, но не принудительное завершение процесса системой. Во время сохранения оставляйте приложение открытым. При обработанной ошибке или отмене незавершённый элемент удаляется; при принудительном завершении может остаться неопубликованный элемент MediaStore до системной очистки.

## Сборка

Нужны JDK 17 с jdk.compiler, Android SDK Platform 35, Build Tools 35.0.0, Bash и Python 3.

```sh
export ANDROID_HOME=/path/to/android-sdk
bash tools/build-sdk.sh
bash tools/build-device-tests.sh
```

Вместо ANDROID_HOME можно задать VEGAS_ANDROID_JAR — путь к API 35 android.jar, и VEGAS_BUILD_TOOLS — каталог Build Tools 35.0.0.

Результат: `build/sdk/Sony_Vegas_Video_v2.3.apk` и `build/device-tests/VegasVideo_device_tests.apk`. AAPT2 компилирует ресурсы и манифест, Java compiler — код, D8 — DEX, zipalign — выравнивание, apksigner — подпись и проверку. Скрипт также проверяет ZIP/CRC, бинарный манифест, DEX и параметры пакета.

Проект можно открыть в Android Studio; конфигурация Gradle 8.9 / AGP 8.7.3 сохранена. Прямая команда при установленном Gradle:

```sh
gradle :app:assembleDebug :app:assembleDebugAndroidTest
```

В публичном репозитории личный ключ отсутствует. При его отсутствии скрипт генерирует временный debug-ключ. Такая CI-сборка не обновляет прежнее приложение с другой подписью. Для постоянной подписи требуется защищённый ключ вне исходников.

## Проверки

Все чистые Java-тесты запускаются командой `bash tools/run-logic-tests.sh`, включая новый SequenceTest. Android-тесты только скомпилированы; фактический запуск на устройстве в этой сессии не выполнялся.

```sh
mkdir -p build/unit
java com.sun.tools.javac.Main --release 8 -d build/unit \
  app/src/main/java/com/personal/sonyvegasvideo/ClipMath.java \
  app/src/main/java/com/personal/sonyvegasvideo/EditHistory.java \
  tests/ClipMathTest.java tests/WorkspaceLogicTest.java
java -cp build/unit com.personal.sonyvegasvideo.ClipMathTest
java -cp build/unit com.personal.sonyvegasvideo.WorkspaceLogicTest
```

Для устройства с USB-отладкой:

```sh
bash tools/run-device-tests.sh
```

Дополнительная проверка реальных Android-виджетов и снимок интерфейса:

```sh
adb shell am instrument -w -e mode ui -e screenshot wide \
  com.personal.sonyvegasvideo.test/com.personal.sonyvegasvideo.ExportInstrumentation
adb exec-out run-as com.personal.sonyvegasvideo cat files/ui-wide.png > ui-wide.png
```

Тесты используют собственный синтетический H.264/AAC-ролик, а не пользовательские файлы. Интеграционные проверки охватывают экспорт с/без звука, B-кадры, поворот, границы и отмену; UI-проверка — меню, импорт, ручки выделения, Undo/Redo, Mute и транспорт. UI-тест временно открывает тестовый ролик и восстанавливает прежние настройки после завершения. Успех обозначается `PASS:` и `INSTRUMENTATION_CODE: -1`. Точный список выполненных проверок указан в `BUILD_VERIFICATION.md`.
