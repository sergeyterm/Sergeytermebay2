# Sony Vegas Video — Android

Личный неофициальный Android-видеоредактор с классической компоновкой Vegas.

Репозиторий предназначен для исходников проекта и сборки APK через GitHub Actions.
Подготовленная версия: 2.3 — импорт, предпросмотр, обрезка, разрезание, удаление,
перестановка и склейка совместимых видеороликов без перекодирования.

Не является официальным приложением Sony/VEGAS или портом Windows-версии.
Ключ личной подписи APK хранится отдельно от публичного репозитория.
