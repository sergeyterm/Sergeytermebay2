# Sony Vegas Video — Android

Личный неофициальный видеоредактор для Android с классической компоновкой Vegas.
Не является продуктом Sony/VEGAS или портом Windows-версии.

Версия 2.3: импорт и предпросмотр, обрезка, монтаж нескольких фрагментов,
разрез по ключевым кадрам, удаление, перестановка, Undo/Redo и склейка
совместимых источников в MP4 без перекодирования.

## GitHub Actions

Workflow `Build and test Vegas Video` запускается при push в main/master
и вручную. Артефакт `Vegas_Video_2.3_CI_APKs` содержит приложение и Android-тесты.
Задание android-tests проверяет экспорт и склейку на эмуляторе Android API 30.
Оценивайте его результат отдельно от успешной компиляции.

CI использует временную debug-подпись. Такой APK не обновляет поверх APK,
подписанного личным ключом из прежних сборок. Личный ключ не хранится в этом
публичном репозитории. Для совместимых обновлений требуется защищённая настройка
постоянного ключа подписания отдельно от исходников.

Для локальной SDK-сборки: JDK 17, Android Platform 35, Build Tools 35.0.0,
Bash и Python 3; запустите `bash tools/run-logic-tests.sh`, затем
`bash tools/build-sdk.sh`. Для тестовой сборки нужен также FFmpeg >= 6.
Синтетический тестовый ролик генерирует `tools/make-test-fixture.sh`.
