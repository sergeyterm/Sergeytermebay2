# ФотоАватар RU — Android 1.2.0

**Статус:** готов исходный Android-проект; подтверждение настоящего видеозвонка возможно только после подключения действующих API-ключей D-ID/ElevenLabs и проверки на устройстве. GitHub Actions собирает **debug APK**, а не подписанный релиз Google Play.

## Возможности

1. **Одна фотография** или **один коллаж 3×3**. Для коллажа прямо в приложении выбирается одна из девяти ячеек, и только **этот фрагмент** отправляется в D-ID. Это **НЕ** реконструкция лица по девяти ракурсам. D-ID V2 Photo Avatar требует одиночный фронтальный портрет; многолицевой коллаж без выбора ячейки может не пройти.
2. Русскоязычный AI-собеседник: имя, тема и предыстория беседы, характер, инструкции на русском. Для речи — D-ID c готовыми голосами Microsoft RU либо ElevenLabs Instant Voice Cloning.
3. **Голосовой референс** из файла MP3/M4A/WAV (через ElevenLabs API), а также ввод уже существующего ElevenLabs Voice ID. Для русского ElevenLabs TTS устанавливается `eleven_flash_v2_5`. Необходимы право использования голоса, подходящий тариф, а иногда подтверждение голоса.
4. Видеозвонок в тёмном мобильном стиле: аватар, состояние связи, кнопки микрофона, звука и завершения разговора. Не является WhatsApp и не связывается с людьми через WhatsApp.
5. Отображение ошибок API, ожидание подготовки D-ID агента, сохранение URI фотографии и голосового референса в локальных настройках (не файлы). Постоянные API-ключи не сохраняются в приложении и не включены в APK.

## Совместимость

Подготовлено с учётом предоставленного bugreport: Samsung SM-F966B, Android 17/API 37, ARM64, внешний и внутренний экраны. `minSdk 26`, `compileSdk 35`, `targetSdk 35`. Наличие `targetSdk 35` не означает, что все ограничения Android 17 протестированы; необходима установка на реальном телефоне.

## Требуемые сервисы и ключи

- D-ID API Key (формат `USER:PASSWORD`), аккаунт с доступом к Agents/Embed и достаточным балансом.
- ElevenLabs API Key, только для собственного голосового референса / Voice ID. Клонирование/голоса могут требовать тариф, верификацию и согласие носителя голоса.
- Ключ **Nuance** использовать нельзя: другой сервис и неподходящий API.
- При создании фотоагента фотография и исходный звук (если выбран клон) передаются соответственно D-ID и ElevenLabs, что требует согласия владельца данных. GitHub Actions не получает этих материалов и ключей.

## Сборка в GitHub Actions

1. Владелец GitHub загружает проект в репозиторий. На ветке `photoavatar-ru-android` предусмотрена автоматическая сборка на `push`.
2. Workflow `.github/workflows/android-apk.yml` устанавливает JDK 17, Android SDK 35, Gradle 8.10.2, запускает проверки и собирает `assembleDebug`.
3. Результат доступен в **Actions → Build Android APK → Artifacts → PhotoAvatarRU-debug-apk**. APK устанавливается вручную; в Android потребуется разрешить установку из текущего источника.

### Локально

Требуется Gradle 8.10.2, JDK 17, Android SDK Platform 35, Build Tools 35.

```bash
python3 -m unittest discover -s tests -p 'test_contract.py' -v
gradle :app:assembleDebug --no-daemon
```

Путь файла сборки: `app/build/outputs/apk/debug/app-debug.apk`.

## Проверки, которые требуется выполнить на реальном телефоне

- Установка APK, запуск, разворачивание/сворачивание устройства, сохранение выбранных файлов после перезапуска.
- Выбор обычного портрета и нужной ячейки коллажа (портрет крупно, чётко, фронтально; лицо не меньше 200×200 пикселей).
- Создание D-ID агента (готовность `done`), авторизация клиентским ключом для WebView origin, видеозвонок через WebRTC и микрофон.
- Русский диалог, язык ElevenLabs-клона, отзывчивость кнопок, временные перебои сети.
- Проверка тарифов, возможных ограничений и модерации изображения и голоса.

**Без API-ключей нельзя подтвердить реальную работу D-ID/ElevenLabs или гарантировать реалистичность.**
