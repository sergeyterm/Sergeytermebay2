# Сведения о совместимости с устройством

**Источник:** предоставленный пользователем Android bugreport ZIP, прочитаны только сведения об устройстве и конфигурации экрана. Полный dumpstate и персональные данные **не включены** в проект.

| Параметр | Полученное значение |
|---|---|
| Производитель | Samsung |
| Модель | SM-F966B |
| Код устройства | q7q |
| Android | 17 |
| API | 37 |
| Процессор ABI | arm64-v8a |
| Локаль | ru-RU / en-US |
| Память | ~11.4 млн КБ по dumpstate |
| Экран (одна из конфигураций) | 1080 × 2520, 490dp по ширине |
| Большой внутренний экран | 1968 × 2184, по состоянию вывода DisplayDeviceInfo |
| Плотность экрана | `ro.sf.lcd_density=420` (системный параметр), активная конфигурация 353 dpi |

В коде нет фиксации портретной ориентации. Применён `resizeableActivity`, управление `WindowInsets` на API 35+, компоненты с изменяемой шириной. Раскладки проверены логически; физического тестирования на Samsung SM-F966B не выполнялось. Для Android 17 совместимость нужно подтвердить установкой APK.
